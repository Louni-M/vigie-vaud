# Rattachement des éléments scrapés par le nom de la commune

Un élément scrapé est rattaché à une commune quand le nom de celle-ci apparaît dans son titre ou sa description,
d'après la liste officielle des communes et une liste d'exclusions pour les noms ambigus (Belmont, Mont-sur-…,
Corcelles…). Sans rattachement, l'élément n'apparaît que dans le fil cantonal. Les dossiers de permis, eux, sont
rattachés par leur position.
